  # Session 3 Summary: Core Architecture, Scene-First Storage, Production Workflows & Multi-Take Versioning

## 1. Scene-First Storage & Directory Hierarchy
- **Transitioned to Scene-First Directory Layout:** Established a clean, self-contained structure: `assets/{scene_name}/{images, videos, audios, workflows, thumbnails}/` with project descriptors saved at `assets/{scene_name}/{scene_name}.json`.
- **Eliminated Ghost & Flat Folders:** Removed hardcoded boot-time directory provisioning loops for `scene01` and legacy flat directories. Enforced Just-In-Time directory creation upon user save/creation.
- **Docker Mount Anchoring:** Anchored all backend path resolvers directly to the container root mount (`/app/assets`), guaranteeing 100% persistence between container restarts.

## 2. Dynamic Workflow Synthesis & Surgical Node Patching
- **Centralized `build_shot_workflow()` Engine:** Unified all ComfyUI workflow generation into a single source of truth inside `backend/services/workflow_service.py`.
- **Dual Format AST Graph Support:** Enabled surgical in-place parameter patching for both **Visual UI Workflow Graphs** (`nodes` array) and **ComfyUI API Dictionaries** (`{ "node_id": {...} }`).
- **Dynamic Parameter & Loader Injections:**
  - Injected expanded prompts into detected multiline/CLIP prompt nodes.
  - Injected assigned media asset filenames into image/video/audio loader nodes with `empty.png` bypass for unassigned slots.
  - Injected sampling steps, megapixels resolution (fixed missing visual canvas handler), and frame duration overrides without mutating graph coordinates, links, or custom nodes.
- **Live Injected Preview & Universal Clipboard:** Updated the web JSON inspector to display live in-memory injected shot JSON and implemented a universal clipboard fallback for HTTP/LAN access.

## 3. Production ZIP Exports & Remote RunPod SFTP Staging
- **Multi-Workflow Production ZIP Bundling:** Refactored the project export handler to package master project JSONs, media assets in `uploads/`, clean master templates in `workflows/`, and **ready-to-run, pre-injected workflows for every single shot** in `staged_workflows/`.
- **Large Archive Ingestion (Fixed HTTP 413):** Updated NGINX configuration with `client_max_body_size 500M;` to support multi-megabyte project ZIPs and 4K source assets.
- **Remote RunPod / ComfyUI Staging:** Automated SFTP staging of all unique shot assets to `/workspace/runpod-slim/ComfyUI/input/` and shot workflows to `/workspace/runpod-slim/ComfyUI/user/default/workflows/{scene_name}/`.

## 4. Assembly Line Prompt Expansion & Over-The-Shoulder (OTS) Framing
- **Assembly Line Architecture:** Separated prompt generation into deterministic Header (Scene Planning + Global Subject Definitions + Directives), LLM-generated Multimodal Description, and deterministic Audio/Music Footer.
- **OTS Spatial Controls:** Added dedicated UI controls for Over-The-Shoulder shots (**Anchor Subject**, **Focus Subject**, and **Framing Side: Left / Right**), hard-injecting precise spatial framing directives into the prompt header.
- **Strict Camera Motion Constraints:** Enforced camera movement rules (e.g. `Locked Off (Static)`) preventing LLM hallucinations like unwanted push-ins.

## 5. On-Demand Lightweight Thumbnail Pipeline
- **Pillow (PIL) Thumbnail Generation:** Automated background creation of lightweight (384px) thumbnails upon image upload.
- **On-Demand Caching Endpoint (`/api/uploads/thumb/{filename}`):** Generates and caches missing thumbnails on the fly for legacy or newly imported files, reducing UI network payloads from 20MB+ down to ~15KB per card.
- **ZIP Exclusion:** Excluded cached thumbnails from export archives to keep bundles lean and pristine.

## 6. Codebase Modularization & Code Hygiene
- **Monolithic Component Decomposition:**
  - Modularized `AssetManagerSection.tsx` (1,600+ lines down to ~200 lines) by extracting `AssetUploadModal`, `AssetEditModal`, `AssetLightbox`, and `AssetSlotGrid`.
  - Refactored `App.tsx` (1,100+ lines) using custom hooks (`useProjectState`, `useWorkflowState`, `useAssetState`).
  - Modularized `GallerySection.tsx` and `WorkflowSection.tsx` into focused sub-components.
- **Backend Service Decoupling:** Began modularizing the 1,400+ line `api.py` into dedicated routers (`project_routes`, `workflow_routes`, `asset_routes`, `execution_routes`) and domain services.

## 7. Multi-Take Versioning System
- **Shot Takes History:** Enhanced `ShotItem` to support a `takes` snapshot array (`Take 1`, `Take 2`, etc.) capturing prompts, parameters, and video outputs per run.
- **Systematic Output Naming:** Saved rendered video outputs with systematic identifiers: `{scene_name}_Shot_{shot_number}_Take_{take_number}.mp4`.
- **Take Management:** Added UI Take Selector pills and "⭐ Hero Take" designation for export prioritization.
